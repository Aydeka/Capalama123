# Capalama

Capalama — это lightweight PWA-проект на чистом HTML, CSS и JavaScript. Изначально это был генератор HEX-палитр, но сейчас проект эволюционирует в более полезный инструмент для пространственного планирования и подбора интерьера.

## Что сейчас есть

### 1) Генератор цветовых палитр
- генерация 5 HEX-цветов;
- фильтры: случайная, пастель, неон, монохром, тёмная и светлая;
- копирование отдельного цвета или всей палитры;
- сохранение палитр в `localStorage`;
- загрузка сохранённой палитры по клику;
- экспорт текущей палитры в PNG через `html2canvas`;
- переключение светлой и тёмной темы;
- PWA-манифест и service worker.

### 2) Помощник по планировке комнаты
- ввод площади комнаты;
- выбор типа помещения: квартира, студия, кухня, гостиная, дом;
- выбор стилевого решения: сканди, лофт, минимализм, тёплый, современный;
- автоматическое зонирование пространства по площади;
- подбор палитры под стиль;
- базовая схема расстановки мебели;
- краткая смета по комнате.

### 3) Автопланировщик мебели по размерам
- пользователь задаёт ширину и глубину комнаты;
- можно добавлять/удалять мебельные элементы с параметрами ширины, глубины и количества;
- система оценивает, помещается ли предмет в комнату;
- по факту отображается логика “влезает / требует корректировки”; 
- планировщику можно быстро проверить реальность расстановки без backend.

## Текущая идея проекта

Проект сейчас находится на этапе MVP: он не пытается стать полноценным ремонтом “сразу всё”, а фокусируется на одной полезной цепочке:

площадь + тип комнаты + стиль -> зонирование + палитра + расстановка + проверка размеров.

То есть это этап между “генератором цветов” и “дизайнерским помощником для интерьера”.

## Техническая реализация

- HTML + CSS + JavaScript
- локальное сохранение в `localStorage`
- статический PWA
- без серверной части
- удобен для GitHub Pages

## Ограничения

- это не полноценный 3D-планировщик;
- без backend и базы данных;
- расчёты ориентировочные, они служат для идеи и ранней вёрстки решения, а не для точной инженерной планировки.

## С PNG не будет работать без backend, так как руки не дошли.

Это историческая ремарка: на текущем этапе проект использует html2canvas в браузере и остаётся статическим, без серверной сборки.
