# Capalama

Capalama — статический PWA-помощник для подбора цветовой палитры и предварительного планирования интерьера.

**Демо:** https://aydeka.github.io/Capalama123/

## Возможности

### Палитры

- генерация пяти HEX-цветов в шести стилях;
- копирование одного цвета или всей палитры;
- сохранение палитр в браузере;
- экспорт палитры в PNG;
- светлая и тёмная темы.

### Планировщик интерьера

- ввод площади и размеров комнаты;
- выбор типа помещения и стиля;
- автоматическое зонирование по площади;
- подбор материалов и палитры;
- архитектурная схема с контурами стен, окнами, дверью и мебелью;
- отдельные рабочие окна «Сводка», «Мебель» и «Схема»;
- добавление, удаление и редактирование мебели;
- проверка, помещаются ли предметы в заданную комнату;
- сохранение планов в браузере.

## Как пользоваться

1. Откройте [демо-версию](https://aydeka.github.io/Capalama123/).
2. В блоке планировщика укажите площадь, тип помещения и стиль.
3. Нажмите «Собрать план».
4. Переключайтесь между окнами «Сводка», «Мебель» и «Схема».
5. В окне «Мебель» изменяйте размеры предметов или добавляйте свои.
6. Сохраните готовый план, если он нужен позже.

## Технологии

- HTML, CSS и JavaScript без фреймворков;
- `localStorage` для локального сохранения данных;
- `html2canvas` для экспорта PNG;
- PWA manifest и service worker;
- публикация через GitHub Pages.

## Запуск локально

Установка зависимостей не требуется. На Windows запустите `start.bat` или откройте `index.html` в браузере.

## Ограничения

Планировщик является концептуальным MVP: схема и расчёты ориентировочные и не заменяют точный проект архитектора или инженерные измерения. Приложение работает без backend, а сохранённые данные доступны только в текущем браузере.
